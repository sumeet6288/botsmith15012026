# 🚨 BotSmith Subscription Renewal Critical Bug Investigation

## Context

We have discovered a critical billing/subscription bug in BotSmith.

### Expected Behavior

1. User purchases a paid plan.
2. Plan remains active until expiry date.
3. After expiry, user sees a **Renew Now** button on the Subscription page.
4. When user clicks **Renew Now**, they should be redirected to the Razorpay payment/subscription flow.
5. Only after successful payment verification should plan features be reactivated.

### Current Bug

After a paid plan expires:

1. Renew Now button appears correctly.
2. User clicks Renew Now.
3. Instead of redirecting to Razorpay/payment page, the system immediately restores the paid plan and paid features.
4. No payment is collected.
5. User receives active subscription access without completing payment.

This is a critical revenue leakage and subscription security issue.
